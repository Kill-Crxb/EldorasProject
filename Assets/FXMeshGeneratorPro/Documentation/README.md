# FX Mesh Generator Pro - Unity Edition

**v1.0.0 RC1 Asset Store Submission**

A production-focused Unity Editor tool for creating game VFX meshes: slash arcs, beam strips, shockwave rings, impact discs, shield domes, helix trails, and cross-energy helixes.

## Highlights
- Clean **Basic / Advanced** workspace modes
- Production Recipes, Sample Pack Generator, and Demo Scene Builder
- Stable on-mesh Flow Preview texture with synchronized Surface Flow Arrows
- Manual Flow Offset controls for direct UV direction validation
- Vertex Alpha Pro preview and packing tools
- Mesh Quality Pass, Mesh Validation Suite, and Full Regression QA
- Publisher/store tools hidden behind Advanced mode and session unlock
- Mobile-oriented Preview LOD and budget warnings

## Quick Start
1. Open `Tools > FX Mesh Generator Pro`.
2. Use **Basic Mode** for normal mesh creation.
3. Select a Mesh Type or Production Recipe.
4. Press `Create / Update Scene Preview Object`.
5. Tune Shape, UV Flow, Vertex Alpha, and Quality.
6. Use `Use Flow Preview`, Surface Flow Arrows, and Flow Offset to validate texture direction.
7. Save a Mesh Asset or material-free Prefab from `Export / Save`.

## Recommended Final QA
Before packaging or sharing the tool, switch to Advanced Mode and run:
- Mesh Validation Suite
- Flow Visual QA
- Full Regression QA
- Demo Scene Builder

## Notes
Generated prefabs are material-free by design. Preview materials and helper overlays are QA tools and are not intended as final game shaders.
