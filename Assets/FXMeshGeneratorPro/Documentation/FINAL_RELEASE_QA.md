# Final Release QA - v1.0.0 RC1 Asset Store Submission

Run this checklist before using the package as a release candidate.

## Basic User Workflow
- [ ] Open the tool.
- [ ] Confirm Basic Mode is clean and publisher tools are hidden.
- [ ] Generate each Mesh Type.
- [ ] Save Mesh Asset.
- [ ] Save Preview Prefab.

## Flow Preview
- [ ] Enable Use Flow Preview.
- [ ] Enable UV Surface Flow Arrows.
- [ ] Test V Forward / V Reverse.
- [ ] Test U Forward / U Reverse.
- [ ] Test Flip U / Flip V.
- [ ] Move Flow Offset through 0, 0.25, 0.5.
- [ ] Confirm helper arrows and material arrows agree.

## Advanced QA
- [ ] Run Mesh Validation Suite.
- [ ] Run Flow Visual QA.
- [ ] Run Full Regression QA.
- [ ] Generate Sample Prefab Pack.
- [ ] Build Demo Scene.

## Package
- [ ] Confirm shader imports without errors.
- [ ] Confirm docs are included.
- [ ] Confirm Generated folder is recreated safely.
