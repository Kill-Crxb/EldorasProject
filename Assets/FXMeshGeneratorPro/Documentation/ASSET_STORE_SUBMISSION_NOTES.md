# FX Mesh Generator Pro - Asset Store Submission Notes

Submission build: **v1.0.0 RC1 Asset Store Submission**

## Unity menu path

The editor window is available only from:

```text
Tools > FX Mesh Generator Pro
```

Duplicate menu entries under `Window` and the top-level `FX Mesh Generator Pro` menu have been removed for a cleaner Asset Store user experience.

## Suggested upload folder

When using Unity Asset Store Publishing Tools, select this folder as the package root:

```text
Assets/FXMeshGeneratorPro
```

The documentation has also been copied into:

```text
Assets/FXMeshGeneratorPro/Documentation
```

so it is included in the uploaded Unity package.
