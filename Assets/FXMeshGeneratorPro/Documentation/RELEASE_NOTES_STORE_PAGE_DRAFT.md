# Release Notes / Store Page Draft

## v1.0.0 RC1 Asset Store Submission
FX Mesh Generator Pro - Unity Edition is a production-focused Unity Editor tool for generating game VFX meshes with UV Flow QA, Vertex Alpha tools, sample packs, demo scene generation, and validation utilities.

### Key Selling Points
- Fast generation of common real-time VFX meshes
- Clean Basic Mode for artists and Advanced Mode for technical QA
- On-mesh UV Flow Preview with synchronized helper arrows
- Vertex Alpha preview/packing utilities
- Sample Pack and Demo Scene Builder
- Mobile-oriented quality and validation tools

### Included Mesh Families
Slash, Beam, Ring, Disc, Dome, Half Dome, Helix, and Cross Helix.
